# Documentation

**Last updated:** 2026-07-28

This folder contains the documentation for this project. Documentation is primarily meant to serve as an introduction/overview for certain parts of the project. Since this project is currently in progress and being written by one person, the docs may become outdated somewhat frequently. To mitigate this, we will try to write the docs in a way that explains the high-level concepts instead of delving into specifics. Please refer directly to the source code if you want a more accurate view of the project.
